# V3X player profile: which bundled plugins V3X-Setup.exe installs, and which are on by default.
# One line per plugin:  <name>  <enabled>  <reason>
#   1 = shipped and loaded            0 = shipped but off (v3x.ini [plugins] <name>=0; the player can
#   turn it on from the main-menu V3X button or v3x.ini)      - = not shipped (developer tools)
# Policy (lead, 2026-11-13): every plugin is preinstalled except pure developer tools; only the
# minimum is on (crash evidence, the main-menu switch and what it needs); the player turns the rest on.
# Sources: docs/plugins.md (catalog, in-game status) and each plugin's header comment.
# make_dist.py fails if a plugin in plugins/ is missing here, so a new plugin is never shipped by accident.
# installer/test_installer.py checks this exact on / off / not-shipped split; change both together.

# --- on: needed by everything else or passive
crash_logger     1  writes v3x/crash.log on a crash: the evidence a player sends with a bug report; read-only
content_packs    1  file overrides from v3x/content_packs/; inert without packs; needed by mod_menu, loc_fallback, script_ext
mod_menu         1  the main-menu "V3X" button: the player's on/off switch for every other plugin; fails closed to the vanilla menu
script_ext       1  passive: hooks nothing; lets plugins ship script/loc/gui packs via content_packs

# --- off: shipped, the player turns them on (main menu > V3X, or v3x.ini)
keep_history     0  country graphs are no longer wiped when switching country; played 4h
ironman_console  0  developer console usable in ironman (multiplayer stays blocked); off because it can matter for achievements
log_filter       0  drops noisy engine log lines; played 4h
frame_pacer      0  timer sleep instead of a busy-wait frame cap, lower fps when idle/background; played 4h
cpu_sched        0  P-/E-core placement on hybrid CPUs, nothing on other CPUs; played 4h
gfx_driver       0  fewer D3D11 driver threads; retries without the flag on failure; played 4h
mem_tuner        0  lower memory commit, one out-of-memory rescue; played 4h
fast_load        0  load timeline + load_transition events other plugins use; optional speedups stay off; played 4h
console_plus     0  Tab completion of console arguments; catalog says not run in game and it had a crash fixed recently (crash6)
loc_fallback     0  English text for keys a mod did not translate; useful for non-English players
enhance          0  only acts in debug mode (binary saves) or with opt-in speed/lean options; catalog: smoke test only
asset_stream     0  forces the texture streamer on; opt-in (its own default is off too)
lazy_mesh        0  faster 3D model loading needs mode=lazy in lazy_mesh.ini; opt-in
sim_opt          0  simulation changes (throttle) are opt-in; single player only; back up saves first
map_cache        0  default mode=measure (reports only); keep-alive needs mode=on in map_cache.ini
mod_loader       0  default mode=measure (reports only); mode=on ran 1h44m in game 2026-11-13: 0 mismatches, 98,786 verified skips (docs/sessions/2026-11-13-evening.md:175)
par_load         0  default mode=measure (reports only)
lazy_gfx         0  default mode=measure (reports only); not run in game
fast_lookup      0  default mode=measure; caused crash5 (fixed); measure ran 1h44m in game 2026-11-13: 1.72 M calls, 0 mismatches (sessions/2026-11-13-evening.md:170)
tick_par         0  read-only tick parallelism analysis (reports only)
ai_par           0  measure-only analysis of AI/economy tick tasks (mode=on refused); fine_chunks is opt-in; not run in game

# --- not shipped: pure developer tools
hello            -  SDK example plugin, logs only
devtools         -  CPU/memory profiler for developers
devconsole       -  reverse-engineering commands (disassembly, memory scans)
devbridge        -  named pipe for the developer MCP server (local tool access to the console)
tick_profiler    -  per-tick-task timing for developers
alloc_tracker    -  allocation tracker, heavy overhead (periodic report = ~0.55 s frame stalls)
